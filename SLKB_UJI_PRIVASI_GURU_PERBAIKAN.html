Uji Privasi Soal Antarguru

Pengujian API Supabase untuk membuktikan soal pribadi Guru A tidak dapat dibaca Guru B. Hanya SELECT; tidak mengedit, menghapus, atau menambahkan data.

1. Status konfigurasi

Memeriksa...

Letakkan file ini sejajar dengan index.html dan folder config pada game. Jangan memasukkan secret key.

2. Soal milik Guru A

ID sudah diisi dari hasil SQL yang Anda kirim. Akun Guru A mempunyai 1 soal pribadi yang ditandai TEST PRIVASI GURU 001.

3. Login akun pengujian

Uji Guru A (pemilik) dahulu, lalu keluar dan uji akun Guru B. Jangan kirim password, token, atau URL berisi token kepada siapa pun.

4. Hasil pengujian

Belum ada pengujian.
Catatan keamanan:

Hasil 0 saat login Guru B merupakan bukti pembatasan baca untuk akun tersebut pada jalur API yang diuji. Untuk membuktikan isolasi antar-pembeli, ulangi juga dengan akun Guru B yang sudah berlisensi Premium. Uji UPDATE/DELETE memerlukan pengujian terpisah yang aman dalam transaksi rollback.
