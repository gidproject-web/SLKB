3. Uji akun Guru Gratis, Guru Premium, dan Admin

Uji akun Guru Gratis terlebih dahulu, keluar, kemudian Guru Premium dan Admin. Password dikirim hanya ke API Supabase proyek ini saat proses login dan langsung dikosongkan dari formulir.
