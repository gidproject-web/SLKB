PANDUAN GURU — IMPOR SOAL SNAKE & LADDER (v1.5.15)

CARA A — MENGGUNAKAN EXCEL (DIREKOMENDASIKAN)
1. Buka template-bank-soal-guruupgradeid.xlsx.
2. Baca sheet PANDUAN; kemudian klik sheet SOAL_IMPOR.
3. Isi satu baris untuk satu soal. Pilih LEVEL, GRADE, SUBJECT, dan ANSWER pada dropdown.
4. Pilih mapel lewat dropdown SUBJECT; Prakarya dan Kewirausahaan tersedia untuk SMA.
   Bila nama mapel belum ada, ketik langsung di kolom SUBJECT (D).
   Jika Excel memperingatkan nama baru, pilih Ya/Lanjutkan agar teks tetap tersimpan.
   Gunakan penulisan yang sama untuk mapel yang sama agar tidak terpecah menjadi kategori ganda.
5. Kolom TOPIC = Bab/Materi. Kolom QUESTION = isi pertanyaan.
   OPTION_A sampai OPTION_D = pilihan, ANSWER = A/B/C/D, EXPLANATION = pembahasan.
   SD kelas 1–3: hanya A–C, kolom OPTION_D kosong dan ANSWER cukup A/B/C.
6. Hapus atau ganti baris contoh. Kolom ID boleh kosong.
7. Saat sheet SOAL_IMPOR sedang aktif: File > Simpan Sebagai > CSV UTF-8 (*.csv).
   Pilih OK/Ya jika Excel menyatakan hanya sheet aktif yang disimpan.
   Jangan menyimpan sheet PANDUAN atau DAFTAR_MAPEL sebagai CSV untuk impor.
8. Simpan file Excel asli sebagai cadangan agar dropdown tidak hilang.

CARA B — MENGGUNAKAN CSV LANGSUNG
1. Klik tombol Template CSV di game setelah memilih Jenjang, Kelas, dan Mapel.
2. Isi kolom tanpa mengganti header dan simpan dengan enkoding UTF-8.
3. Gunakan tanda kutip CSV standar jika teks soal berisi koma, titik koma, atau baris baru.

LANGKAH IMPOR KE GAME
1. Login sebagai Premium/Admin; menu Bank Soal.
2. Klik Impor CSV / JSON dan pilih file .csv hasil langkah di atas.
3. Perhatikan notifikasi jumlah soal berhasil diimpor.
4. Pilih filter Jenjang, Kelas, Mata Pelajaran, Materi untuk mengecek hasil.
5. Kembali ke Mulai Bermain dan pilih kategori yang sama.

FAQ
Q: Bolehkah mengunggah .xlsx langsung?
A: Belum. Pilih CSV UTF-8 terlebih dahulu agar game tetap ringan/offline.
Q: Jika mapel tidak ada di dropdown?
A: Ketik nama mapel baru langsung di kolom SUBJECT Excel/CSV. Saat impor,
   game menampilkan konfirmasi mapel baru, lalu soal akan menjadi kategori tersendiri.
   Pastikan ejaan konsisten. Pada Tambah Soal Manual juga tersedia pilihan Lainnya.
Q: Apakah JSON masih bisa?
A: Ya. JSON tetap didukung.
Q: Berapa soal dalam sekali impor?
A: Maksimal 1.000 soal per berkas; disarankan 1 bab/mapel per impor.
Q: Apakah soal akan diacak saat dimainkan?
A: Ya bila Acak Urutan Soal aktif. Siklus 20/50/100/Semua tetap tersedia.
